# 🚀 Site-Base — Boilerplate de Funil CRO de Alta Conversão

Template moderno e modular em **React + Tailwind CSS + Lucide Icons**, projetado como a *"mãe de todos os funis"* de infoprodutos, apostilas e materiais visuais (baseado nas melhores práticas de CRO do mercado brasileiro, como `carne-inss.lovable.app` e `materialseguro.site`).

## ⚡ Inicialização Rápida

```bash
# Instalar dependências
npm install

# Rodar servidor local de desenvolvimento
npm run dev

# Gerar build otimizado para produção
npm run build
```

## 🛠️ Personalização Rápida em Arquivo Único
Toda a copy, preços, links de checkout (Hotmart, Kiwify, etc.), fotos, bônus, depoimentos e perguntas frequentes são controlados em um único arquivo:

👉 [`src/config/siteData.ts`](src/config/siteData.ts)

## 📁 Componentes Inclusos
- **TopBanner:** Barra de escassez e urgência.
- **Hero:** Headline tricolor de alto impacto, espaço de mockup 3D e bullets com checkmarks.
- **ClaritySection:** Foto da capa principal e carrossel de páginas/slides (`slide-marquee`).
- **InteractiveWidget:** Simulador dinâmico de perfil/categoria para engajamento pré-checkout.
- **StudySection:** Carrossel de fotos de pessoas usando o material (`study-marquee`) com gatilho de urgência.
- **DarkBanner:** Bloco contrastante de quebra de objeções e alívio de dor.
- **TargetAudience:** Grid de 6 perfis ideais de clientes.
- **BonusSection:** 6 Bônus com fotos e mockups 3D empilhados com valor riscado (`GRÁTIS`).
- **PricingOffer:** Card de checkout completo `#oferta` com contador social e garantia.
- **WhatsAppTestimonials:** Carrossel de conversas reais de WhatsApp com fotos de perfil e duplo check azul.
- **GuaranteeSection:** Medalha geométrica oficial de 7 dias de garantia incondicional.
- **AccessSteps:** 4 Ilustrações SVG vetoriais do passo a passo de compra.
- **FAQ:** Accordion limpo para eliminação de dúvidas.
- **StickyCTA:** Botão fixo no polegar para conversão em smartphones.
- **Footer:** Disclaimers legais e aviso de material independente.
